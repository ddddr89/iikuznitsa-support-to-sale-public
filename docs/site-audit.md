# Аудит конкурсного стенда

Дата проверки — 26 ноября 2026 года. Публичные страницы проверены в Chrome
на ширинах 1280, 390 и 320 px. Регрессии с созданием заявок, документами
и входом менеджера выполнены с отдельной SQLite и тестовым токеном.

## Дизайн

- Сверены палитра `#A20C33`, `#A6A8AB`, `#2396D3`, `#686968` и варианты
  логотипа для белого и бордового фона. Тикер SOFL сохранён в исходных PNG.
  Логотипы сохраняют пропорции, под белый вариант в подвале выделено
  охранное поле. [Softline Guideline 2025, стр. 8–11, 15–16 и 47](</home/demon/лого софтлайн/лого софтлайн/Softline Guideline 2025 (1).pdf>)
- Браузер загрузил обе локальные вариации Montserrat. Заголовки используют
  его при отсутствии Nekst. Оба шрифта предусмотрены веб-типографикой
  брендбука. [Softline Guideline 2025, стр. 20](</home/demon/лого софтлайн/лого софтлайн/Softline Guideline 2025 (1).pdf>)
- Бордовый фон главного блока сохранён. Укорочены главный блок и зона между
  началом чата и полем ввода. Передача вопроса теперь раскрывается рядом
  с перепиской, после отправки появляется переход в «Мои заявки».

## Дефекты и исправления

| Обнаружено | Исправление |
| --- | --- |
| На 320 px плашка «Конкурсный прототип» перекрывала название. | Убран отрицательный отступ. Проверено отсутствие пересечения на 320, 390 и 1280 px. |
| После 503 сообщение оставалось в переписке, повтор создавал второй пузырь. | Удаляется только несохранённое сообщение, текст остаётся в поле для повторной отправки. |
| Перезагрузка возвращала интерфейс к пустому чату. | Восстанавливаются собственные сохранённые сообщения из сессии браузера. |
| Случайная витрина и вложенная прокрутка затрудняли чтение результатов каталога. | На старте есть форма поиска, дальше показываются товары по запросу или из ответа помощника. На странице до шести результатов поиска. |
| Место для передачи вопроса отделялось от переписки каталогом. | Заявка раскрывается внутри чата и при необходимости получает текст последнего вопроса. |
| Сводка заявки не обозначала раскрытие, обновление закрывало историю. | Добавлен индикатор раскрытия, открытые заявки сохраняются при обновлении списка. |
| После повторного открытия обращения менеджер должен был заново создавать документы, чтобы получить кнопки скачивания. | Раздел «Готовые документы» использует уже сохранённые КП и проекты счетов. |
| После выхода история и черновик были скрыты интерфейсом, но оставались в DOM. | Выход удаляет историю, черновик и кнопки сохранённых документов. |

## Проверки и границы

- Публичный Chrome прошёл главную, чат, вкладку «Мои заявки» и экран
  входа менеджера. Браузер не зарегистрировал ошибок JavaScript и
  горизонтального скролла. Через n8n получен живой ответ YandexGPT по
  Dell U2424H с реальной карточкой каталога.
- Изолированный Chrome прошёл поиск, пагинацию, клавиатурное переключение вкладок,
  шаблон вопроса, повтор отправки после 503, восстановление истории чата,
  передачу обращения менеджеру, добавление и удаление позиции, создание
  и повторное скачивание КП и проекта счёта, выход из кабинета.
- Демонстрационный сценарий дополнительно проверяет ответ менеджера,
  утверждение ответа для базы знаний и запрет чужого доступа к заявке и
  документу. Имитированные HTML-сущности декодируются как текст без
  создания HTML-элементов. Тестовая SQLite используется для всех действий
  с заявками и документами. Прошли дымовая проверка API, 15 конкурсных
  и 20 модульных тестов.
- Резервная ветка OpenAI отключена. Экран оплаты и подтверждение покупки
  остаются в планах. Формируемый счёт имеет статус проекта.

Снимки до изменений в `.stand/audit/before/`, снимки после изолированного
прогона в `.stand/audit/after/`. Для воспроизведения запустите FastAPI
на 18092 с отдельной SQLite, демокаталогом `data/demo.csv` и тестовым
`MANAGER_TOKEN`, затем выполните `node tests/site_audit.mjs`.
