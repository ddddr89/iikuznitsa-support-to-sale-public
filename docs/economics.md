Действующий вебхук передаёт счётчики последнего вызова модели. Строка с
инструментом n8n поэтому отражает часть расходов. Для сценария полного
вызова инструмента приведено отдельное измерение через прямой Responses API.
Вызовы GPT‑5.4 mini не измерялись.

## Исходные значения для расчёта

| Поле | Значение |
| --- | --- |
| Модель и режим | YandexGPT Pro 5.1, синхронный |
| Единица тарификации | 1000 токенов |
| Входящие токены | 0,8 ₽ за 1000, включая НДС |
| Кешированные токены | 0,8 ₽ за 1000, включая НДС. Уже входят в число входящих. |
| Исходящие токены | 0,8 ₽ за 1000, включая НДС |
| Вызов локального поиска | Локальный FTS5, отдельного модельного тарифа на внешний вызов в расчёте нет. Возвращённый контекст входит в измеренные токены. |
| Один запрос клиентского чата на действующем n8n без инструмента | 258 × 0,8 / 1000 = **0,2064 ₽** |
| Один запрос с поисковым инструментом, оценка прямого маршрута | 711 × 0,8 / 1000 = **0,5688 ₽** |
| Консультация из двух запросов, прямой маршрут | 2017 × 0,8 / 1000 = **1,6136 ₽ за диалог**, или **0,8068 ₽ на сообщение** |

Формула запроса — сумма входящих и исходящих токенов по всем модельным
вызовам в одном сообщении, умноженная на 0,0008 ₽. Для сценария с двумя
сообщениями можно также показать стоимость полного диалога. Для усреднения
по эксплуатации нужны доли сценариев и статистика повторных вызовов.
[Тарифы Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing)

Иллюстрация нагрузки из кейса, 500 обращений в день и условные 30 дней.
Если каждое обращение соответствует измеренному одиночному маршруту n8n,
получается 103,20 ₽ в день или 3 096 ₽ в месяц за модель. Если каждое
соответствует измеренной двухшаговой консультации, оценка составляет
806,80 ₽ в день или 24 204 ₽ в месяц. Это два условных сценария без
стоимости VPS, сопровождения и времени менеджера.

Для воспроизведения прямых замеров
установите `YANDEX_MODEL=yandexgpt-5.1` и запустите `.venv/bin/python -m demo.measure`
с уже настроенными учётными данными.
