## Заполненный официальный калькулятор

Файл `iikuznitsa-calculator.xlsx` заполнен в исходной структуре шаблона.
В листе «Расчёт» сохранены формулы, объединения, стили и валидация валюты.
Публичная версия содержит два вызова одного обращения с поиском по каталогу
через n8n. В строке 9 записаны 216 входящих и 18 исходящих токенов, в строке 10
— 319 входящих и 48 исходящих. Каждый вызов учтён один раз. Итог I13 по
формуле — **0,39409836 ₽ без НДС** за измеренное обращение, или **0,4808 ₽
с НДС**. Для пересчёта использован тариф 800 ₽ за миллион токенов с НДС и
ставка 22%. Цена без НДС — 800 / 1,22 = 655,737704918 ₽ за миллион.
Курс доллара не применяется. [Тариф Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing) · [Ставка НДС](https://yandex.cloud/ru/blog/vat-changes-ru-2025) · [Шаблон организатора](https://drive.google.com/file/d/1TjQRRsfafywe193cGyENUNq0VkkGCQxN/view)

## Исходные значения для расчёта

| Поле | Значение |
| --- | --- |
| Модель и режим | YandexGPT Pro 5.1, синхронный |
| Единица тарификации | 1000 токенов |
| Входящие токены | 0,8 ₽ за 1000, включая НДС |
| Кешированные токены | 0,8 ₽ за 1000, включая НДС. Уже входят в число входящих. |
| Исходящие токены | 0,8 ₽ за 1000, включая НДС |
| Вызов локального поиска | Локальный FTS5, отдельного модельного тарифа на внешний вызов в расчёте нет. Возвращённый контекст входит в измеренные токены. |
| Один запрос клиентского чата на действующем n8n без инструмента | 258 × 0,8 / 1000 = **0,2064 ₽** |
| Один запрос с поисковым инструментом, оценка прямого маршрута | 711 × 0,8 / 1000 = **0,5688 ₽** |
| Консультация из двух запросов, прямой маршрут | 2017 × 0,8 / 1000 = **1,6136 ₽ за диалог**, или **0,8068 ₽ на сообщение** |

Формула запроса — сумма входящих и исходящих токенов по всем модельным
вызовам в одном сообщении, умноженная на 0,0008 ₽. Для сценария с двумя
сообщениями можно также показать стоимость полного диалога. Для усреднения
по эксплуатации нужны доли сценариев и статистика повторных вызовов.
[Тарифы Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing)

По стоимости измеренного двухвызовного сценария без НДС модель стоит
197,05 ₽ при 500 обращениях за полгода (гипотеза, требующая подтверждения)
и 394,10–788,20 ₽ в месяц при 1 000–2 000 обращениях в месяц. В PDF
кик-оффа указан другой ориентир — около 500 обращений в день. Фактическая
нагрузка требует сверки. VPS, эксплуатация и поддержка в этих оценках не
учтены.

Отдельная иллюстрация для 500 обращений в день и условных 30 дней
по прежним модельным замерам с НДС.
Если каждое обращение соответствует измеренному одиночному маршруту n8n,
получается 103,20 ₽ в день или 3 096 ₽ в месяц за модель. Если каждое
соответствует измеренной двухшаговой консультации, оценка составляет
806,80 ₽ в день или 24 204 ₽ в месяц. Это два условных сценария без
стоимости VPS, сопровождения и времени менеджера.

Для воспроизведения прямых замеров
установите `YANDEX_MODEL=yandexgpt-5.1` и запустите `.venv/bin/python -m demo.measure`
с уже настроенными учётными данными.

## Сверка расходов и оценка пилота

Публичный XLSX повторно скачан по ссылке из конкурсных материалов. В XML
книги подтверждены 216/18 и 319/48 входящих/исходящих токенов, формулы общей
группы I8:I12 и итог I13 `SUM(I9:I12)` с сохранённым значением 0,394098360655738 ₽.
Хеш SHA-256 файла начинается с `3cf2e11b9281da9d`. Это измерение отдельного
двухвызовного запроса. Полная статистика токенов по 100 сценариям недоступна:
счётчики клиенту не выдаются, а тела исполнений не сохраняются.

Безопасная сверка фактических начислений возможна по поресурсной разовой
выгрузке Yandex Cloud Billing. Владелец платёжного аккаунта или пользователь
с ролью `billing.accounts.viewer` может получить CSV за период замеров и
отфильтровать строки по каталогу проекта и продукту AI Studio. Для сравнения
достаточно обезличенных строк с периодом, единицей потребления, объёмом и
начислением. Пароли, API-ключи и токены для передачи выгрузки не требуются.
В общей учётной записи детализация по дню и каталогу не доказывает стоимость
одного обращения, если в том же каталоге были другие вызовы. Выделенная
выгрузка в рабочем каталоге не обнаружена. [Экспорт детализации](https://yandex.cloud/ru/docs/billing/operations/get-folder-report)

Подтверждённых платёжных данных по VPS в рабочем каталоге нет. Если
подтверждённая доля VPS проекта за месяц — V ₽, её вклад составит V/1 000,
V/2 000 или V/15 000 ₽ на обращение при соответствующем месячном объёме.
Например, при 15 000 обращений, каждое из которых повторяет измеренный
двухвызовный сценарий, расчёт модели без НДС даёт 5 911,48 ₽ в месяц; VPS и
операторская работа добавляются отдельно.

Для ориентировочной оценки внедрения в пилоте учтите четыре работы —
загрузка и проверка данных, настройка доступов и маршрутов, приёмочные
сценарии с менеджером, запуск мониторинга. Сценарная стоимость разовой
работы равна сумме часов этих работ, умноженной на согласованную ставку
исполнителей. Ежемесячно отдельно учитываются доля VPS, сопровождение,
вызовы моделей и время менеджеров. Нормативов времени и фактической ставки
для такого расчёта пока нет.
