# Экономика YandexGPT

Измерение 26 ноября 2026 года. [Счётчики API по каждому вызову](token-usage.csv)
получены на контрольных запросах к явно заданной модели YandexGPT Pro 5.1.
В первом сценарии поиск SKU сделал два обращения к модели. В сценарии
консультации два пользовательских сообщения тоже дали два обращения.
В n8n измерение включает один вызов Text Generation. Для него API не показал
разбивку по кешу.

| Сценарий | Вызовы | Вход | Из них кеш | Выход | Стоимость по прайсу, ₽ |
| --- | ---: | ---: | ---: | ---: | ---: |
| SKU и поисковый инструмент | 2 | 626 | 0 | 85 | 0,5688 |
| Вопрос по доставке | 1 | 713 | 0 | 33 | 0,5968 |
| Консультация с уточнением | 2 | 1 805 | 384 | 212 | 1,6136 |
| Один запрос через n8n | 1 | 225 | — | 12 | 0,1896 |

Для синхронной модели Pro 5.1 ставка за 1 000 входящих, кешированных и
выходных токенов одинакова и составляет 0,8 ₽ с НДС. Токены кеша уже включены
во входящие. Локальный поиск реализован пользовательской функцией, отдельный
тариф на встроенные инструменты здесь не применяется. [Тарифы Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing)

Расчёт для калькулятора: сложить `total_tokens` по всем обращениям пользователя
и умножить на 0,0008 ₽. Стоимость рассчитана по прайсу и фактическим счётчикам,
без данных закрывающих документов. В стоимости нет VPS, сопровождения и
времени менеджера. Контрольная выборка мала. Для прогноза используйте собственную
долю коротких запросов и консультаций. Вызовы GPT-5.4 mini не измерялись.
