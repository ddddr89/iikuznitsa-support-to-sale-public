# Каталог Softline

Публичная версия поставляется с синтетическими товарами в `data/demo.csv`. Для полного импорта требуется предоставленная организаторами выгрузка.

## Полная выгрузка и обновление

Полный снимок на стенде взят из предоставленной организаторами выгрузки YML. Файл хранится за пределами репозитория.

Для YML передайте ожидаемое число предложений. Импорт распознаёт gzip по сигнатуре и читает поток через `iterparse`, удаляя обработанные элементы из XML-дерева. SKU берётся из `offer@id`, а `vendorCode` индексируется для поиска по артикулу производителя. Несколько предложений могут иметь один артикул производителя. Название берётся из `name` либо собирается из `typePrefix`, `vendor` и `model`. Цена отсутствует у недоступных товаров и для валют за пределами RUB/RUR. CSV принимает тот же формат, что и демонстрационный файл, с ценой в копейках.

```bash
.venv/bin/python -m app.catalog_feed "$APP_DB_PATH" --file "$SOFTLINE_YML_PATH" --expected-count "$SOFTLINE_EXPECTED_COUNT"
.venv/bin/python -m app.catalog_feed "$APP_DB_PATH" --expected-count "$SOFTLINE_EXPECTED_COUNT"
.venv/bin/python -m app.catalog "$APP_DB_PATH" "$SOFTLINE_CSV_PATH" --source softline_feed --expected-count "$SOFTLINE_EXPECTED_COUNT"
```

Используйте команду, подходящую для формата источника. Для загрузки по сети передайте конечную HTTPS-ссылку в `SOFTLINE_FEED_URL` через окружение. Значение ссылки может содержать токен доступа. Скачивание выполняется во временный файл до замены SQLite. Обновление атомарно пересобирает индекс FTS5 и записывает источник, число SKU и время импорта. Дублирующиеся SKU, повреждённая выгрузка и расхождение числа позиций сохраняют предыдущий снимок. Уже созданные КП сохраняют зафиксированные цены.

При проверке 26 ноября 2026 года загружены 136 040 предложений из 292 МБ XML. Пиковая память процесса импорта по `/usr/bin/time` составила 29 312 КиБ, время — 13,95 секунды. SQLite подтвердила целостность базы. Поиск по каталогу проверен по артикулу производителя и русскоязычным запросам.

## Ежедневная синхронизация

На VPS используется пара `deploy/iikuznitsa-catalog-sync.{service,timer}`. Таймер с `Persistent=true` запускает синхронизацию ежедневно в 04:00 по Москве. Команда — `.venv/bin/python -m app.catalog_feed .stand/catalog.sqlite3 --remote`. Этот режим использует HTTPS и принимает полный ответ HTTP 200 без перенаправления. При отсутствии адреса завершается ошибкой. Локальный файл не используется как резерв.

Оператор сохраняет подтверждённый поставщиком конечный URL в переменной `SOFTLINE_FEED_URL` в файле `/home/demon/.config/iikuznitsa/catalog-sync.env` с правами 0600. Если поставщик требует заголовок авторизации, его значение задаётся там же в `SOFTLINE_FEED_AUTHORIZATION`. За скачиванием следует проверка даты YML, полного разбора XML, полей, уникальности SKU и объёма снимка. Дата без смещения трактуется как московское время. Максимальный возраст сетевого снимка — 48 часов. По умолчанию сокращение относительно текущей базы отклоняется. Для согласованной замены с меньшим числом предложений оператор задаёт точное подтверждённое число в `SOFTLINE_EXPECTED_COUNT`; после разового изменения его можно удалить. Минимальный порог сам по себе не доказывает полноту произвольного частичного фида, поэтому необходим официальный адрес полного снимка.

Импорты из CLI используют общий замок. Каталожные таблицы, артикулы производителя, FTS5 и квитанция успешной синхронизации обновляются одной транзакцией. Заявки, документы, сессии и база знаний не пересоздаются. Результат попытки виден в `journalctl -u iikuznitsa-catalog-sync.service`, успешная квитанция доступна менеджеру через `GET /api/v1/catalog/status`. Квитанция хранит фактическое время загрузки, дату YML, размер, SHA-256 и число предложений. URL и секреты в квитанцию не записываются.

Аудит 27 ноября 2026 года не нашёл прежнего таймера, cron и настроенного HTTPS-адреса. Известен файл, переданный организаторами, с датой формирования 25 ноября. Запись импорта 136 040 позиций датирована 26 ноября 2026 года, 17:38:53 UTC. Это локальный импорт. Новый таймер включён. Ручной контрольный запуск его службы 27 ноября в 14:53:59 UTC завершился до скачивания с сообщением об отсутствии `SOFTLINE_FEED_URL`. Диагностика подтвердила, что запись последней успешной сетевой синхронизации отсутствует. Автоматическая синхронизация остаётся неподтверждённой до подключения официального HTTPS-источника.

Запрос в Softline: «Просим предоставить конечный HTTPS-адрес полного регулярно обновляемого товарного фида Softline Store в YML/XML либо gzip, способ авторизации, требования к исходному IP и доступ к нему с конкурсного VPS. Просим уточнить часовой пояс и частоту публикации, а также способ проверить целостность и полноту снимка, например число предложений или контрольную сумму. Если адрес содержит токен, передайте его по закрытому каналу».
