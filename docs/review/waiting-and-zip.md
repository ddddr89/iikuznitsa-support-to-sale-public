# Проверка очереди менеджера и ZIP

Проверено на публичном стенде в отдельных аудиторских клиентских сессиях. Демонстрационные заявки и их история не изменялись.

| Проверка | Наблюдение |
| --- | --- |
| Очередь при открытом чате | Вопрос о сроке поставки создал ожидающее обращение. Оно отображалось выше обычной заявки на оформление с бейджем «Требует ответа». |
| Переходы и счётчик | «Ожидает ответа» → «В работе» сохранило подсветку, счётчик 4 → 4. После «Ответ отправлен» счётчик стал 3 и бейдж исчез. |
| Закрытие | Попытка закрыть ожидающее обращение без ответа и причины вернула 422. При закрытии с причиной её видит менеджер. В истории клиента причина не показывается. |
| Ответ | Сообщение менеджера появилось в уже открытом клиентском чате один раз. |
| Получение архива | «Подготовить документы» создало пакет за одно действие. В блоке готовых документов у менеджера и клиента доступна одна кнопка «Скачать документы» для этого пакета. |
| Содержимое | Из обоих скачанных архивов извлечены и прочитаны два PDF: «Коммерческое предложение.pdf» и «Проект счёта.pdf». В обоих артикул 465223, количество 3, цена 26 173 ₽ за единицу, итог 78 519 ₽. Содержимое PDF для обеих ролей совпало. |
| Права | У владельца ZIP выдаётся как `application/zip` с заголовком загрузки. Чужая клиентская сессия получила 404, менеджерский маршрут без токена — 401. |

Независимый признак `requires_reply` хранится для новых записей и меняется отдельно от статуса. Для старых записей колонка остаётся пустой; историческое «В работе» без ответа трактуется как ожидающее, потому что исходный признак не сохранялся. Обычная новая заявка на оформление не получает приоритет при переводе в работу. У существующих строк и истории обратного заполнения нет.

Архив формируется из сохранённых PDF. Проект счёта сохраняет пометку о непригодности для оплаты. Старые отдельные маршруты PDF и данные расчёта сохранены.

В публичном профиле для чата добавлен лимит 12 запросов в минуту на действующую cookie-сессию. Общий предел 30 запросов на процесс сохранён. IP-лимит, настройки удалённого доступа и денежный потолок облака не изменялись. Тесты используют временную SQLite или помеченные заявки; обращения на стенде закрыты после проверки.

Прошли 56 модульных тестов, 16 конкурсных тестов и smoke API. В Chrome проверены ширины 1280, 390 и 320 px. Живой запрос прошёл рабочий n8n → YandexGPT и вызвал инструмент поиска.
