## Новая сводка без смешения прогонов

- Исходная публикация **75 PASS / 21 PARTIAL / 4 FAIL** остаётся без изменений.
- Повторная редакторская оценка исходного прогона по бизнес-критерию **81 PASS / 15 PARTIAL / 4 FAIL**. Действительно исполненная передача в №26, 27, 28, 57, 59, 60 не дефект агента.
- Исторические 14 повторов независимо дают **13 PASS / 1 PARTIAL / 0 FAIL**, поскольку у №6 неподтверждённое наличие. Это выборка, которая отдельно подтверждает устранение всех четырёх исходных FAIL.
- Ни редакторскую оценку, ни отдельный повтор нельзя выдавать за свежий прогон всех 100. Новая правка прошла профильную локальную регрессию. Координатору переданы номера 6, 7, 24, 86, 87, 90, 94 для проверки на стенде после интеграции.

## Реализованные правки и доказательства

- Короткие запросы точного монитора Dell U/P переходят к точному каталожному варианту с предупреждением, что количество и поставку подтверждает менеджер. Явная формулировка «Вызови поиск по каталогу …» сохраняет ранее существовавший инструментальный путь. Чтение реального снимка подтвердило SKU 472221 и цену 26 569 ₽. [Выбор маршрута](../app/catalog_matching.py)
- Лицензирование Windows Server использует уже сообщённые сведения. Для двух физических CPU по 12 ядер и трёх Windows Server ВМ расчёт **24 за комплект, 48 для трёх ВМ** дан при условии одного хоста только для размещения и управления ВМ и лицензирования по физическим ядрам. CAL, условия закупки и цена передаются на проверку. Точные SKU не обещаны. [Руководство Microsoft по Windows Server 2025](https://www.microsoft.com/licensing/guidance/Windows-Server-2025)
- Самовывоз, обмен для юрлица и расчёт доставки используют существующий официальный источник. Возврат остаётся темой второго хода; транспортировка не получает необоснованной цены или срока. Вопрос о неизвестном SLA даёт способ посмотреть текущее обращение без повторного автоматического создания. Прямая просьба к менеджеру остаётся отдельной веткой до консультации. [Консультации](../app/catalog_advice.py) · [Справочник Softline](https://store.softline.ru/delivery_info/)
- **24 профильных теста прошли** в изолированной SQLite. Добавлены пять тестов для короткого запроса Dell, уточнения Windows Server, самовывоза и продолжения обмена, указанного индекса и повторной реплики про SLA. Снимок товаров и базу знаний проверял в режиме чтения. [Профильные тесты](../tests/test_catalog_matching.py)

## Оставшиеся риски качества

Свободный ответ n8n может обобщать наличие и другие коммерческие условия за пределами точного маршрута Dell. Следующий безопасный шаг — проверять утверждения о наличии структурно, а не только инструкцией модели. Истории закупок, совместимость и условия корпоративных лицензий ограничены верифицированными фактами фида и документации. Для общей дедупликации любых последующих сообщений нужны подтверждённые границы темы, потому что две независимые задачи одной сессии должны оставаться двумя обращениями.
