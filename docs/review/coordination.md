## Пересчёт и новые доказательства

Исходный прогон остаётся **75 PASS / 21 PARTIAL / 4 FAIL**. По критерию кейса шесть корректно квалифицированных и переданных менеджеру сценариев считаются завершёнными. Оценка тех же исходных трасс по этому критерию составляет **81 / 15 / 4**. Это переоценка, а не новый прогон. Из 14 прежних повторов независимая проверка признаёт **13 PASS и 1 PARTIAL** из-за неподтверждённого обещания наличия по № 6. Четыре исходных FAIL отдельно проверены успешными повторами. [Исходные данные отчёта](../audit-100.md)

На опубликованной версии отдельно проверены семь затронутых сценариев. По критерию завершения агентом все семь прошли. Автоматическая проверка оставила № 24 в PARTIAL, поскольку подтверждённая лицензия не показана; по результату ручной проверки это корректное завершение через менеджера. Суммарной новой оценки по 100 сценариям нет, так как вся сотня не повторялась.

Независимое ревью не подтвердило P0. Из P1 закрыт ближайший риск очереди. В публичном профиле ручная запись требует активной сессии, при отказе модели бесхозная эскалация не создаётся, ручная и автоматическая запись используют общий минутный лимит. На стенде подтверждены HTTP 403 без сессии, HTTP 201 у владельца, HTTP 404 у другой сессии и HTTP 401 менеджерского API без токена. Платный маршрут n8n → YandexGPT и фид из 136 040 записей работают. Лимит процесса не заменяет лимит бюджета, а лимит сессии сам по себе не защищает от массового создания сессий.

На финальной версии прошли 52 модульных и 15 конкурсных тестов, а также smoke API. Проверка Chrome подтвердила приоритет и подсветку очереди, изоляцию, доставку ответа в открытый чат и восстановление после перезагрузки. Два PDF совпали по позициям и сумме 78 519 ₽. Помеченные записи закрыты.
