# Предконкурсный аудит Support-to-Sale AI

26 ноября 2026 года · публичный HTTPS-стенд · версия приложения `8f16edc`.

**Итог — 9/18 по шкале жюри.** По 20 сценариям — **5 PASS, 8 PARTIAL, 7 FAIL**. Первая серия — 3/5/2; вторая — 2/3/5.

PASS означает, что достигнут основной результат сценария без существенной ошибки. PARTIAL означает, что запрос продвинулся, но остались неподтверждённые условия или нерелевантные рекомендации. FAIL означает существенный сбой подбора по условиям клиента.

Десять отдельных сессий через публичные HTTP API, тот же маршрут, которым пользуется клиентский чат. Время измерено от отправки POST до чтения ответа. Диалоги записаны на стенде. Для проверки документов использованы отдельные синтетические обращения, затем закрытые; записи жюри не использованы. Данные ответов и карточек ниже получены от стенда. Markdown-разметка и переносы строк адаптированы для таблицы.

- 16 сообщений, все HTTP 200. История совпала с отправленными сообщениями во всех 10 сессиях. Автоматических заявок по этим сценариям — 0.
- Медиана **0.716 с**, диапазон **0.050–3.051 с**. Это разовый замер без нагрузочного теста.
- Во всех ходах API отметил локальный поиск в каталоге и базе знаний. **К** — FastAPI вернул ответ по проверенным карточкам без модели. **Я** — FastAPI → n8n → YandexGPT, API не зарегистрировал модельный вызов инструмента. Статус поиска по каталогу в начале запроса не равнозначен вызову инструмента моделью.
- Все **18 уникальных ссылок** открылись с HTTP 200; заголовки товарных страниц совпали с карточками. Название, артикул, категория, цена и URL всех карточек совпали с локальным снимком. Это подтверждает происхождение карточки, а не актуальный остаток магазина или пригодность лицензии. Часть ссылок базы знаний повторяется или не подтверждает конкретный ответ.

Это замер одного обращения, а не средняя стоимость всех 20 сценариев. ## Готовность и ROADMAP

**Готово для показа:** публичный HTTPS-чат, поиск реального SKU, подбор по ограниченному набору проверяемых характеристик, честная обработка цены по запросу, n8n и инструмент, история и личные заявки, кабинет менеджера, статус и ответ, КП и проект счёта, изоляция доступа. Приём оплаты в чате отсутствует; проект счёта сам по себе не подтверждает заказ.

**Остаётся в ROADMAP:** гарантированная проверка составных требований и лицензирования, актуальные остатки и расписание обновлений, стабильное наследование ограничений между ходами, промышленная идентификация клиентов и менеджеров, мониторинг и статистика качества и затрат, интеграция с учётным контуром. Для сдачи отдельно сверить версию публичного калькулятора и доступность финальной ссылки на видео. Аудит не меняет приложение, n8n, конфигурацию или видео.
