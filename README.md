# Support-to-Sale AI

Публичная версия содержит исходный код и историю разработки.
Локально используйте синтетический каталог. Фирменные изображения,
исходная выгрузка и материалы заказчика доступны на стенде по условиям
конкурса и не входят в этот репозиторий.


Прототип для кейса «Агент поддержки» в треке «Клиентские сценарии» хакатона «ИИкузница». [Открыть конкурсный стенд](https://iikuznitsa.ydna.tech/).

Помощник отвечает на вопросы об ассортименте Softline, подбирает варианты по описанию потребности и передаёт обращение менеджеру. Менеджер видит контекст, отвечает клиенту, формирует PDF коммерческого предложения и проект счёта. Подтверждённые ответы сохраняются в базе знаний.

## Что показать жюри

1. В режиме клиента спросите про Dell U2424H, затем опишите потребность без названия товара. Например, подберите монитор для рабочего места с ноутбуком и USB‑C. В ответе видны карточки, если каталог подтверждает подходящие позиции.
2. Передайте вопрос менеджеру и откройте «Мои заявки». Для записи используйте тестовый контакт в домене `example.invalid`.
3. В режиме менеджера откройте заявку, измените статус и подготовьте КП и проект счёта. Клиент может скачать свои документы. Доступ к кабинету защищён токеном, который передаётся отдельно.
4. Сохраните обезличенный ответ и задайте тот же вопрос в чате. Помощник вернёт подтверждённый текст из базы знаний.

## Как работает

FastAPI обслуживает интерфейсы и API. SQLite хранит каталог, заявки, клиентские сессии, документы и индекс знаний. Последний проверенный снимок каталога содержит 136 040 предложений Softline. Поиск использует артикул, код производителя и полнотекстовый индекс FTS5.

Часть вопросов обрабатывается правилами подбора или подтверждённой базой знаний. Для консультаций с моделью FastAPI обращается к n8n и YandexGPT Pro 5.1. Модель может один раз вызвать поиск и получить до пяти карточек. При сбое вебхука FastAPI пробует прямой YandexGPT, если он настроен. Если оба маршрута недоступны, клиент получает каталожный ответ. При наличии действующей сессии вопрос может перейти в очередь менеджера. Ветка GigaChat отключена.

## Локальный запуск

Нужны Python 3.12 и SQLite с FTS5. Для PDF в Linux установите шрифт DejaVu Sans (например, пакет `fonts-dejavu-core` для Ubuntu). Для обработки фирменного PDF и разбора результатов тестов нужен Poppler (`poppler-utils`). Команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
export APP_DB_PATH=./demo.sqlite3
.venv/bin/python -m app.catalog "$APP_DB_PATH" data/demo.csv
read -rsp 'Токен менеджера: ' MANAGER_TOKEN
export MANAGER_TOKEN
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 18080 --no-access-log
```

Главная — `http://127.0.0.1:18080/`, кабинет — `/manager`, OpenAPI — `/docs`. При локальном запуске без настроек модели работает каталожный режим. Для PDF используются ReportLab и шрифт DejaVu Sans. Для переноса элементов фирменного шаблона используется `pdftoppm`.

Публичный репозиторий содержит код, синтетические данные, зависимости, workflow и тесты. Полный фид, файлы переписок, шаблон КП, SQLite, токены и сертификаты хранятся отдельно. Публичный конкурсный стенд работает через Nginx и выделенный systemd unit `iikuznitsa-support-to-sale.service`.

### Запуск с моделью

Импортируйте workflow в свой n8n, настройте учётные данные во внешнем окружении и укажите адрес своего API каталога в узле «Поиск в каталоге». Указанный в экспорте адрес используется конкурсным стендом. Инструкция содержит настройку локального Basic Auth ingress, YandexGPT и прямого запасного маршрута. [Настройка n8n](n8n/README.md)

### Обновление данных на стенде

```bash
.venv/bin/python -m app.catalog_feed .stand/catalog.sqlite3 --file /путь/к/выгрузке.yml --expected-count 136040
.venv/bin/python -m app.knowledge .stand/knowledge.sqlite3 "$APP_MATERIALS_DIR"
```

Каталог обновляется атомарно. При ошибке или несовпадении числа позиций сохраняется прежний снимок. Для авторизованного HTTPS-импорта предусмотрен `SOFTLINE_FEED_URL`. Владелец материалов задаёт `APP_MATERIALS_DIR` и при необходимости `APP_QUOTE_TEMPLATE`.

## Проверка

```bash
bash tests/run-smoke.sh
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
npm install --prefix .stand/tools --no-audit --no-fund playwright
bash demo/run.sh
DEMO_MOBILE=1 DEMO_OUT=.stand/demo-mobile bash demo/run.sh
```

Локальный Playwright использует Chrome, отдельную временную SQLite, синтетический каталог и тестовый токен. Для PDF-проверки нужен `pdftotext`. Путь к установленному Chrome задаётся через `CHROME_BIN`, порт через `DEMO_PORT`. Артефакты пишутся в исключённый из Git каталог `.stand/`. Smoke-набор проверяет HTTP и SQLite на синтетических данных. Отдельно на публичном стенде пройдены 100 браузерных сценариев. После целевых повторов зафиксировано 99 PASS, 1 PARTIAL и 0 FAIL. [Итоги браузерной приёмки](docs/final-release-checklist.md#приёмка-на-публичном-стенде)

## Границы версии

Заявки привязаны к браузерной сессии на семь дней. Оплата, подтверждение покупки и интеграция со складскими остатками остаются за пределами текущей версии. Документ «Проект счёта» предназначен для проверки менеджером. Тарифная оценка модели приведена отдельно от затрат на инфраструктуру и работу менеджера.
