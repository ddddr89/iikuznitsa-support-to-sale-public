## Что умеет прототип

- **Известный товар.** Помощник ищет точную модель или артикул и уточняет недостающие параметры, в том числе редакцию, срок и количество для лицензий.
- **Подбор по потребности.** Помощник уточняет задачу, проверяет бюджет и обязательные характеристики, сравнивает варианты и объясняет рекомендацию по доступным данным. При изменении ограничений пересчитывает подбор. При изменении количества выбранного товара пересчитывает сумму.
- **Оформление.** По запросу клиента готовит КП и счёт в PDF по подтверждённым SKU, каталожной цене и количеству. Оба файла доступны в чате и пакетом в «Моих заявках». Счёт предназначен для проверки реквизитов и условий оформления. Оплата по нему не предусмотрена.
- **Менеджер.** По явной просьбе клиента передаёт контекст в очередь «Требует ответа». Пока заявка ожидает ответа, повторная просьба использует ту же запись. После ответа или закрытия новая просьба создаёт новую запись. Ответ сохраняется в исходной переписке.
- **Знания.** Подтверждённые источники используются при ответе. Автоматическое пополнение проверено на двух темах: статус заказа и переход к оформлению из корзины. Менеджер может вручную публиковать проверенные обезличенные ответы.

## Как работает

FastAPI обслуживает веб-интерфейсы и API. SQLite хранит 136 040 предложений из конкурсной выгрузки Softline, заявки, сессии и документы. Поиск использует артикулы, коды производителя, индекс FTS5, описания и доступные структурированные характеристики. Основной источник цены, характеристик и расчётов — предоставленный фид. Витрина Softline служит дополнительным источником. В текущих PDF неизвестный НДС не рассчитывается и не прибавляется к цене.

Простые запросы обслуживают правила приложения и база знаний. Для модельной консультации FastAPI вызывает n8n и YandexGPT Pro 5.1. Модель может запросить поиск по каталогу и получить его результаты во втором вызове. FastAPI проверяет заявленные коммерческие сведения по источникам. При сбое n8n предусмотрен прямой маршрут к YandexGPT, если он настроен. Ветка GigaChat отключена. PDF формирует ReportLab. Стенд работает по HTTPS через Nginx, приложение запускает systemd.

## Локальный запуск

Нужны Python 3.12 и SQLite с FTS5. Для PDF в Linux установите шрифт DejaVu Sans (например, пакет `fonts-dejavu-core` для Ubuntu). Для обработки фирменного PDF и разбора результатов тестов нужен Poppler (`poppler-utils`). Команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
export APP_DB_PATH=./demo.sqlite3
.venv/bin/python -m app.catalog "$APP_DB_PATH" data/demo.csv
read -rsp 'Токен менеджера: ' MANAGER_TOKEN
export MANAGER_TOKEN
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 18080 --no-access-log
```

Главная — `http://127.0.0.1:18080/`, кабинет — `/manager`, OpenAPI — `/docs`. При локальном запуске без настроек модели работает каталожный режим. Для PDF используются ReportLab и шрифт DejaVu Sans. Для переноса элементов фирменного шаблона используется `pdftoppm`.

Публичный репозиторий содержит код, синтетические данные, зависимости, workflow и тесты. Полный фид, файлы переписок, шаблон КП, SQLite, токены и сертификаты хранятся отдельно. Публичный конкурсный стенд работает через Nginx и выделенный systemd unit `iikuznitsa-support-to-sale.service`.

### Запуск с моделью

Импортируйте workflow в свой n8n, настройте учётные данные во внешнем окружении и укажите адрес своего API каталога в узле «Поиск в каталоге». Указанный в экспорте адрес используется конкурсным стендом. Инструкция содержит настройку локального Basic Auth ingress, YandexGPT и прямого запасного маршрута. [Настройка n8n](n8n/README.md)

### Обновление данных на стенде

```bash
.venv/bin/python -m app.catalog_feed .stand/catalog.sqlite3 --file /путь/к/выгрузке.yml --expected-count 136040
.venv/bin/python -m app.knowledge .stand/knowledge.sqlite3 "$APP_MATERIALS_DIR"
```

Каталог обновляется атомарно. При ошибке или несовпадении числа позиций сохраняется прежний снимок. Для авторизованного HTTPS-импорта предусмотрен `SOFTLINE_FEED_URL`. Владелец материалов задаёт `APP_MATERIALS_DIR` и при необходимости `APP_QUOTE_TEMPLATE`.

## Проверка

```bash
bash tests/run-smoke.sh
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
npm install --prefix .stand/tools --no-audit --no-fund playwright
bash demo/run.sh
DEMO_MOBILE=1 DEMO_OUT=.stand/demo-mobile bash demo/run.sh
```

Локальная регрессия использует Chrome, отдельную временную SQLite и синтетические данные. Для PDF нужен `pdftotext`. На программном релизе `697ea64` от 28 ноября 2026 прошли 112 модульных и 17 конкурсных проверок. Целевая проверка Chrome на этом релизе подтверждает передачу менеджеру, очередь, доставку ответа и сохранение после F5. Отдельные проверки документов и подбора проводились на предыдущих программных коммитах. Исторические серии перечислены в журнале релиза с указанием границ их применимости. ## Границы версии

Сессия браузера ограничена семью днями. Сетевое обновление конкурсного фида не подтверждено. Прототип не осуществляет оплату, не подтверждает складские остатки и не подставляет неизвестную ставку НДС. Подтверждённые токены и тарифная оценка модели отделены от выставленных начислений, инфраструктуры и времени менеджера. [Пояснительный расчёт](docs/usage-sample.xlsx) · [Дорожная карта](ROADMAP.md)
